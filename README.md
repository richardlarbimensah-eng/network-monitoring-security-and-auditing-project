# network-monitoring-security-and-auditing-project
This my repository for my network monitoring security and auditing project
TOPIC:
Integrating Ticketing Systems with Security Alerting for Automated Case Management
SHORT SUMMARY:
This project focuses on monitoring SSH authentication logs generated by an Ubuntu Server. The implementation is limited to detecting brute-force attacks performed using Hydra within a controlled virtual laboratory. The project demonstrates attack detection and alert generation using Graylog SIEM. TheHive integration is presented as a proposed extension because the available hardware could not support its full deployment.
